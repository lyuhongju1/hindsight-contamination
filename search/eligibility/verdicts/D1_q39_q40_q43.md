Caveats for q43:
- Program identity. The DUNE documents in the candidate file belong to a different collaboration and are not used. LArIAT re-uses the ArgoNeuT cryostat and refurbished TPC ("LArIAT Phase-1 will re-use the existing ArgoNeuT cryostat ... and its refurbished LArTPC"), and its leads overlap with ArgoNeuT. However, it is formally a new collaboration, the "LArIAT Collaboration". I count it as the upgrade of the baseline detector; the coordinator should confirm it meets "upgrade program / declared successor of the same collaboration".
- I2 margin. The gap is 25 months. A pre-arXiv Fermilab LArIAT proposal (T-1034, around 2013) could carry an earlier commitment date and break I2; it was not checked because it has no arXiv text.
- Other LArIAT changes were excluded: cold front-end electronics (readout), the liquid-phase purification skid (engineering), and new wire planes of unchanged geometry.
