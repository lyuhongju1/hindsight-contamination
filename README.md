# Hindsight contamination: project folder

This folder holds the materials for a standalone paper on hindsight contamination in AI-assisted detector design. The companion availability paper (submitted) is in `..\APS Open RR\`.

| Path | What |
|---|---|
| `hindsight_contamination_study_design.md` | v1 design, as originally written; superseded |
| `RUNBOOK.md` | **Start here**: operating log, pipeline status, actions only the PI can take |
| `hindsight_contamination_study_design_v3.md` | **Current design**: solo operation by Claude; changes relative to v2 |
| `hindsight_contamination_study_design_v2.md` | Base design: recognizability ladder, distractor difference-in-differences, claim ladder, the referee report applied in advance (§14a) |
| `pair_selection_rules.md` | Frozen rules for choosing new baseline–upgrade pairs, ready to freeze |
| `candidate_pairs_PILOT.md` | Candidate pairs written by a model; **pilot use only** |
| `power\` | Power simulation from the APS variance components. Start with `README.md` |
| `search\` | INSPIRE search, logging and random-draw tool (run by Claude) |
| `_obsolete\experts\` | Panel materials from before the switch to solo operation; not used |
| `registry\` | Prospective registry protocol and candidate pending decisions |
| `ligo_T1300433_check.md` | Leftover APS date check; not needed for this paper, safe to delete |
